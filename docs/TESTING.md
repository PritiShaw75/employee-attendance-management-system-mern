# Testing Checklist

1. Start MongoDB.
2. Start backend.
3. Run `node seed.js`.
4. Start frontend.
5. Login as employee.
6. Check in.
7. Check out.
8. Verify working hours.
9. Submit a leave request.
10. Login as HR.
11. Check employee count.
12. Check attendance data.
13. Check leave deduction.
14. Test wrong password.
15. Test logout.
